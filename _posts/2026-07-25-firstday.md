# welcome to my first post! right now, i'll talk about the making of this blog!

now, going into this project, i knew little to *NOTHING* about making a website, purchasing a domain, and hosting content on it.<br>
all my previous knowledge comes from strawpage and neocities, which both are more streamlined versions of website building and design.

the very first thing i did before researching basic html, how to add elements to my site, or how to HOST it in general, was buy the domain.<br>
..which, may have been stupid.

but of course, the domain is the heart of the website! *kalii.site* could be iconic! *kaliicappy.site* maybe looks a little cleaner, but id like to stay away from that name for now, keep it a little personal!

..only thing is, its kaliibloggy. not kaliisite. i *could* just change the name to kaliisite, but kaliibloggy is kinda funny, and you cant buy a *kaliiblog.gy* domain name, which sucks.

after buying the domain, it brought me to a dashboard that i had no idea how to use, and the basic descriptions it had on the website weren't helping, especially because it tried to get me to purchase more things just to create and host the website myself, which, frankly, i did not want to do.

[a friend](https://switchyduck.xyz/) told me about *Github Webhosting*, which sounded good. i've already got a github account, so why not? 

setting up for github was.. not fun.

making *github pages* was easy, just a few extra clicks when making a repository, but linking the website back to the domain sucked.
in order to connect them, you have to put in a whole lot of ip adresses to where you bought the domain from to point it at where to get the content from, so it can display it on your own site. it would be nice if it was explained on either site specifically how to do it though. i had to go through whatever the new google ai threw at me to piece together the sites.

eventually, since you're seeing this, it worked!

other than that, im learning html still, ive got hyperlinks, embedding gifs and elements, and basic formatting down. other things i'd certainly have to do more research on.
speaking of embedding gifs, [GifCities](https://gifcities.org/] is good for those 'old-internet' style gifs from geocities, if you're into those.

otherwise, this website will be updated every day (hopefully) and with a song (hopefully) as well!

heres this post's song, Hard To Explain by The Strokes.
